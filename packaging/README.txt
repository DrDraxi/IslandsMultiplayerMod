Islands of Insight Multiplayer mod {VERSION}
=====================================================

INSTALL
1. In Steam: right-click Islands of Insight > Manage > Browse local files.
   That opens the game folder (the one with IslandsofInsight.exe in it).
2. Copy the "IslandsofInsight" folder from this zip into it, and say yes when
   Windows asks to merge the folders.
   The files end up in IslandsofInsight\Binaries\Win64, next to
   IslandsofInsight-Win64-Shipping.exe. (Not Engine\Binaries\Win64.)
3. Start the game from Steam as usual.

PLAY TOGETHER (title screen)
- Everyone needs this same version ({VERSION}).
- PLAY ONLINE: joins a public session with room (up to 10 players), or starts one.
- PLAY WITH FRIENDS: starts a friends-only session. Friends join with "Join Game"
  in the Steam friends list, or accept a Steam invite (Shift+Tab overlay).
- PLAY OFFLINE: no session. Accepting a Steam invite still works.

You'll see each other with your own customization, name, title and level, on the
map, and each other's name at the mouse when you're in the same grid puzzle.

IN GAME
- Chat: Enter to type, Enter to send, Esc to cancel.
- Pause menu > INVITE opens Steam's invite dialog for your session.

SteamVR STARTS WITH THE GAME?
That's the game's own VR plugin, not this mod. Add  -nohmd  to the game's Steam
launch options (Properties > General > Launch options) to turn it off.

UNINSTALL
Delete dwmapi.dll, UE4SS.dll, UE4SS-settings.ini, steam_api64.dll and the Mods
folder from IslandsofInsight\Binaries\Win64.

PROBLEMS
Send UE4SS.log from IslandsofInsight\Binaries\Win64.
